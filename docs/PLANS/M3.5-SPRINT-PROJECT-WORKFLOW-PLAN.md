**ProjectsService.findAll logic:**
```typescript
async findAll(actor: CurrentActor) {
  if (actor.role === 'ADMIN' || actor.role === 'HR') {
    return this.prisma.project.findMany({
      where: { deletedAt: null },
      include: { pm: true, members: { include: { user: true } } },
    });
  }

  if (actor.role === 'DEPARTMENT_HEAD') {
    return this.prisma.project.findMany({
      where: {
        OR: [
          { createdById: actor.id },
          { pmId: actor.id },
          ...(actor.departmentId ? [{ departmentId: actor.departmentId }] : []),
        ],
        deletedAt: null,
      },
      include: { pm: true, members: { include: { user: true } } },
    });
  }

  if (actor.role === 'PM') {
    return this.prisma.project.findMany({
      where: {
        OR: [
          { pmId: actor.id },
          { members: { some: { userId: actor.id, projectRole: 'PM' } } },
        ],
        deletedAt: null,
      },
    });
  }

  // EMPLOYEE
  return this.prisma.project.findMany({
    where: { members: { some: { userId: actor.id } }, deletedAt: null },
  });
}
```

## 9. RISK & MITIGATION

| # | Risk | Impact | Mitigation |
|---|------|--------|------------|
| R1 | Burndown performance với sprint dài (nhiều tasks) | Medium | Cache daily snapshot, chỉ recalc khi task update |
| R2 | DEPT_HEAD confusion (không hiểu tại sao không tạo sprint) | Medium | UI tooltip: "Bạn có quyền giám sát, liên hệ PM để thay đổi" |
| R3 | Cron DAILY reset gây load server | Low | Chạy 00:00 timezone VN, batch update |
| R4 | WIP limit UX (user không hiểu) | Low | Tooltip giải thích + visual warning trước khi move |
| R5 | Sprint ACTIVE conflict (2 ACTIVE cùng lúc) | High | Service check trước khi start, throw 409 |
| R6 | Project list query chậm với data lớn | Medium | Add index trên (departmentId, deletedAt), pagination |
| R7 | DEPT_HEAD đổi phòng → orphan projects | Medium | Soft transfer: trước khi đổi department, assign project sang DEPT_HEAD mới |
