## 0. TỔNG QUAN

### 0.1. Mục tiêu

Khi cuộc họp chuyển sang trạng thái **COMPLETED**, hệ thống tự động dùng **Google Gemini 1.5 Flash** phân tích nội dung biên bản (`MeetingMinute.content`) và trích xuất 4 thành phần:

| # | Thành phần | Mô tả | Format lưu trữ |
|---|------------|--------|-----------------|
| 1 | **Summary** | Tóm tắt tổng quan cuộc họp 3-5 đoạn | String (`aiSummary`) |
| 2 | **Action Items** | Danh sách công việc cần làm + assignee + deadline | `Json` (`actionItems`) |
| 3 | **Decisions** | Các quyết định quan trọng đã đưa ra | `Json` (`decisions`) |
| 4 | **Risks & Open Questions** | Rủi ro & câu hỏi chưa được giải quyết | `Json` (`risksAndQuestions`) |

### 0.2. Tận dụng từ M6 (đã có)

- ✅ **Gemini SDK** đã cài (`@google/generative-ai`)
- ✅ **Pattern Gemini call** đã có ở `document-ai.service.ts` (replicate)
- ✅ **Fallback heuristic** cho trường hợp API fail

### 0.3. Cần làm mới

- ❌ Extend `MeetingMinute` schema (4 field mới)

- ❌ Wire trigger vào 2 nơi auto-complete meeting

```typescript
// File: backend/src/meetings/meeting-ai.service.ts

import { Injectable, Logger } from '@nestjs/common';
import { PrismaService } from '../prisma/prisma.service.js';
import { GoogleGenerativeAI } from '@google/generative-ai';

export interface MeetingSummaryResult {
  summary: string;
  actionItems: ActionItem[];
  decisions: string[];
  risksAndQuestions: {
    risks: string[];
    openQuestions: string[];
  };
  model: string;
  tokensUsed?: number;
}

export interface ActionItem {
  task: string;
  assignee?: string;
  deadline?: string;
  priority?: 'HIGH' | 'MEDIUM' | 'LOW';
  confidence?: number;
}

@Injectable()
export class MeetingAiService {
  private readonly logger = new Logger(MeetingAiService.name);

  constructor(private readonly prisma: PrismaService) {}

  /**
   * Generate full AI summary for a meeting
   * Triggers: auto on COMPLETED + manual via API
   */
  async generateSummary(meetingId: string): Promise<MeetingSummaryResult> {
    const meeting = await this.prisma.meeting.findUnique({
      where: { id: meetingId },
      include: {
        minutes: true,
        attendees: { include: { user: { select: { name: true } } } },
      },
    });

    if (!meeting || !meeting.minutes) {
      throw new NotFoundException('Meeting hoặc MeetingMinute không tồn tại');
    }

    const content = meeting.minutes.content;
    if (content.length < 50) {
      this.logger.warn(`Meeting ${meetingId} content too short (${content.length} chars). Skip AI.`);
      throw new BadRequestException('Biên bản quá ngắn để tóm tắt (cần ≥ 50 ký tự)');
    }

    // Get API key from system config hoặc env
    const systemConfig = await this.prisma.systemConfig.findFirst();
    const apiKey = systemConfig?.geminiApiKey || process.env.GEMINI_API_KEY;

    if (apiKey) {
      try {
        const result = await this.callGemini(apiKey, content, meeting);
        await this.saveSummary(meetingId, result);
        await this.updateLinkedDocumentSummary(meetingId, result);
        return result;
      } catch (error) {
        this.logger.warn(`Gemini failed for meeting ${meetingId}: ${(error as Error).message}. Using fallback.`);
      }
    }

    // Fallback heuristic
    const fallback = this.generateHeuristicSummary(content, meeting);
    await this.saveSummary(meetingId, fallback);
    return fallback;
  }

  private async callGemini(
    apiKey: string,
    content: string,
    meeting: { title: string; attendees: Array<{ user: { name: string } }> }
  ): Promise<MeetingSummaryResult> {
    const genAI = new GoogleGenerativeAI(apiKey);
    const model = genAI.getGenerativeModel({
      model: 'gemini-1.5-flash',
      generationConfig: { responseMimeType: 'application/json' },
    });

    const attendees = meeting.attendees.map(a => a.user.name).join(', ');

    const prompt = `
Bạn là trợ lý AI chuyên phân tích biên bản cuộc họp doanh nghiệp. Hãy phân tích biên bản sau và trả về JSON với cấu trúc chính xác:

{
  "summary": "Tóm tắt tổng quan 3-5 đoạn văn ngắn gọn, súc tích, bằng Tiếng Việt",
  "actionItems": [
    {
      "task": "Mô tả công việc cần làm (bắt buộc)",
      "assignee": "Tên người phụ trách (nếu đề cập, không có thì null)",
      "deadline": "YYYY-MM-DD (nếu đề cập deadline cụ thể, không có thì null)",
      "priority": "HIGH | MEDIUM | LOW (dựa trên ngôn ngữ)",
      "confidence": 0.0-1.0
    }
  ],
  "decisions": ["Quyết định quan trọng 1", "Quyết định quan trọng 2"],
  "risksAndQuestions": {
    "risks": ["Rủi ro 1", "Rủi ro 2"],
    "openQuestions": ["Câu hỏi chưa giải quyết 1"]
  }
}

Quy tắc:
- Action items: chỉ trích xuất task CỤ THỂ có người phụ trách hoặc deadline, bỏ qua câu chung chung
- Decisions: các quyết định đã được đồng ý trong cuộc họp
- Risks: rủi ro được nêu trong cuộc họp
- Open Questions: câu hỏi chưa có câu trả lời cuối cùng
- Nếu không có dữ liệu cho section nào, trả về mảng rỗng
- Sử dụng Tiếng Việt trong toàn bộ output

Thông tin cuộc họp:
- Tiêu đề: ${meeting.title}
- Thành viên tham dự: ${attendees}

Nội dung biên bản:
"""
${content.substring(0, 15000)}
"""

Trả về JSON hợp lệ, không kèm markdown code block.
`;

    const result = await model.generateContent(prompt);
    const responseText = result.response.text().trim();
    const parsed = JSON.parse(responseText) as Omit<MeetingSummaryResult, 'model' | 'tokensUsed'>;

    // Validate structure (defensive)
    return {
      summary: parsed.summary || '',
      actionItems: Array.isArray(parsed.actionItems) ? parsed.actionItems : [],
      decisions: Array.isArray(parsed.decisions) ? parsed.decisions : [],
      risksAndQuestions: {
        risks: Array.isArray(parsed.risksAndQuestions?.risks) ? parsed.risksAndQuestions.risks : [],
        openQuestions: Array.isArray(parsed.risksAndQuestions?.openQuestions) ? parsed.risksAndQuestions.openQuestions : [],
      },
      model: 'gemini-1.5-flash',
      tokensUsed: result.response.usageMetadata?.totalTokenCount,
    };
  }

  private generateHeuristicSummary(
    content: string,
    meeting: { title: string; attendees: Array<{ user: { name: string } }> }
  ): MeetingSummaryResult {
    // Heuristic: lấy 3-5 câu đầu tiên + detect action items bằng regex
    const sentences = content
      .split(/(?<=[.!?])\s+/)
      .map(s => s.trim())
      .filter(s => s.length > 15);

    const summary = sentences.slice(0, 5).join(' ');

    // Detect action items bằng pattern: "Tên + sẽ/được giao/phụ trách + verb"
    const actionItemRegex = /([A-ZÀ-Ỹ][a-zà-ỹ]+(?:\s+[A-ZÀ-Ỹ][a-zà-ỹ]+)*)\s+(sẽ|được giao|phụ trách|nhận|lo|cần)\s+([^.!?\n]{10,150})/g;
    const actionItems: ActionItem[] = [];
    let match;
    while ((match = actionItemRegex.exec(content)) !== null) {
      actionItems.push({
        task: match[3].trim(),
        assignee: match[1].trim(),
        confidence: 0.5,
        priority: 'MEDIUM',
      });
    }

    // Detect decisions bằng keyword
    const decisions: string[] = [];
    const decisionKeywords = ['quyết định', 'thống nhất', 'đồng ý', 'sẽ chọn', 'sẽ dùng'];
    for (const sentence of sentences) {
      if (decisionKeywords.some(kw => sentence.toLowerCase().includes(kw))) {
        decisions.push(sentence);
      }
    }

    return {
      summary: summary || `Cuộc họp "${meeting.title}" với ${meeting.attendees.length} thành viên. Nội dung chi tiết xem trong biên bản.`,
      actionItems: actionItems.slice(0, 10),
      decisions: decisions.slice(0, 5),
      risksAndQuestions: { risks: [], openQuestions: [] },
      model: 'fallback-heuristic',
    };
  }

  private async saveSummary(meetingId: string, result: MeetingSummaryResult): Promise<void> {
    await this.prisma.meetingMinute.update({
      where: { meetingId },
      data: {
        aiSummary: result.summary,
        actionItems: result.actionItems as any,
        decisions: result.decisions as any,
        risksAndQuestions: result.risksAndQuestions as any,
        aiGeneratedAt: new Date(),
        aiModel: result.model,
        aiTokensUsed: result.tokensUsed ?? null,
      },
    });
  }

  /**
   * Update linked Document (M6 U4) with summary nếu đã được auto-create
   */
  private async updateLinkedDocumentSummary(meetingId: string, result: MeetingSummaryResult): Promise<void> {
    try {
      const linkedDoc = await this.prisma.document.findFirst({
        where: { linkedMeetingId: meetingId, deletedAt: null },
      });
      if (linkedDoc && !linkedDoc.aiSummary) {
        await this.prisma.document.update({
          where: { id: linkedDoc.id },
          data: { aiSummary: result.summary },
        });
      }
    } catch (err) {
      this.logger.warn(`Failed to update linked Document: ${(err as Error).message}`);
    }
  }
}
```

```typescript
private async autoCompleteOverdueMeetings(): Promise<void> {
  const now = new Date();
  const overdueMeetings = await this.prisma.meeting.findMany({
    where: {
      status: { in: [MeetingStatus.SCHEDULED, MeetingStatus.IN_PROGRESS] },
      endTime: { lt: now },
      deletedAt: null,
    },
    select: { id: true, hasMinutes: { select: { id: true } } }, // pseudo
  });

  for (const m of overdueMeetings) {
    await this.prisma.meeting.update({
      where: { id: m.id },
      data: { status: MeetingStatus.COMPLETED },
    });

    // ⭐ M5.1: Trigger AI summary async (non-blocking)
    this.meetingAiService.generateSummary(m.id).catch(err => {
      this.logger.warn(`Auto AI summary failed for ${m.id}: ${err.message}`);
    });
  }
}
```

```typescript
// Thêm vào backend/src/meetings/meetings.controller.ts

@Post(':id/ai-summary/generate')
@Roles('ADMIN', 'PM', 'DEPARTMENT_HEAD')  // Ai có thể regenerate
async generateAiSummary(
  @Param('id') id: string,
  @CurrentUser() user: User,
) {
  // RBAC: chỉ creator hoặc Admin
  const meeting = await this.meetingsService.findOne(id, user);
  if (meeting.createdById !== user.id && user.role !== 'ADMIN') {
    throw new ForbiddenException('Chỉ người tạo cuộc họp hoặc Admin mới có thể regenerate');
  }
  return this.meetingAiService.generateSummary(id);
}

@Get(':id/ai-summary')
async getAiSummary(
  @Param('id') id: string,
  @CurrentUser() user: User,
) {
  await this.meetingsService.findOne(id, user); // Check access
  const minute = await this.prisma.meetingMinute.findUnique({
    where: { meetingId: id },
    select: {
      aiSummary: true,
      actionItems: true,
      decisions: true,
      risksAndQuestions: true,
      aiGeneratedAt: true,
      aiModel: true,
    },
  });

  if (!minute || !minute.aiSummary) {
    return { hasSummary: false };
  }

  return {
    hasSummary: true,
    summary: minute.aiSummary,
    actionItems: minute.actionItems,
    decisions: minute.decisions,
    risksAndQuestions: minute.risksAndQuestions,
    generatedAt: minute.aiGeneratedAt,
    model: minute.aiModel,
  };
}
```

```typescript
      const result = await meetingApi.generateAiSummary(meetingId);
      setSummary({ hasSummary: true, ...result });
      toast.success('AI đã tóm tắt cuộc họp');
    } catch (err) {
      setError('Tạo AI summary thất bại. Vui lòng thử lại.');
    } finally {
      setGenerating(false);
    }
  };

  if (loading) return <div className="p-6 text-slate-500">Đang tải AI summary...</div>;

  if (!summary || !summary.hasSummary) {
    return (
      <div className="p-6 bg-slate-50 rounded-2xl border border-slate-200/80">
        <div className="flex items-center gap-3 mb-3">
          <Sparkles className="text-purple-600" size={20} />
          <h3 className="text-sm font-semibold text-slate-900">AI Tóm tắt cuộc họp</h3>
        </div>
        <p className="text-sm text-slate-600 mb-4">
          Chưa có AI summary. {canRegenerate ? 'Nhấn nút bên dưới để tạo.' : 'Sẽ tự động tạo khi cuộc họp kết thúc.'}
        </p>
        {canRegenerate && (
          <Button onClick={handleGenerate} disabled={generating} variant="primary">
            {generating ? 'Đang tạo...' : 'Tạo AI Summary'}
          </Button>
        )}
      </div>
    );
  }

  return (
    <div className="space-y-4">
      {/* Header */}
      <div className="flex items-center justify-between">
        <div className="flex items-center gap-3">
          <div className="p-2 bg-purple-50 rounded-xl">
            <Sparkles className="text-purple-600" size={18} />
          </div>
          <div>
            <h3 className="text-sm font-semibold text-slate-900">AI Tóm tắt</h3>
            <p className="text-xs text-slate-500">
              {summary.model === 'gemini-1.5-flash' ? 'Gemini 1.5 Flash' : 'Heuristic'} •
              {summary.generatedAt && ` ${new Date(summary.generatedAt).toLocaleString('vi-VN')}`}
            </p>
          </div>
        </div>
        {canRegenerate && (
          <Button onClick={handleGenerate} disabled={generating} variant="ghost" size="sm">
            <RefreshCw size={14} className={generating ? 'animate-spin' : ''} />
            Regenerate
          </Button>
        )}
      </div>

      {/* Summary Text */}
      <div className="p-4 bg-white rounded-xl border border-slate-200/80">
        <p className="text-sm text-slate-700 leading-relaxed">{summary.summary}</p>
      </div>

      {/* Action Items */}
      {summary.actionItems && summary.actionItems.length > 0 && (
        <div className="p-4 bg-white rounded-xl border border-slate-200/80">
          <div className="flex items-center gap-2 mb-3">
            <ListTodo className="text-amber-600" size={16} />
            <h4 className="text-sm font-semibold text-slate-900">Action Items ({summary.actionItems.length})</h4>
          </div>
          <ActionItemList items={summary.actionItems} />
        </div>
      )}

      {/* Decisions */}
      {summary.decisions && summary.decisions.length > 0 && (
        <div className="p-4 bg-white rounded-xl border border-slate-200/80">
          <div className="flex items-center gap-2 mb-3">
            <CheckCircle2 className="text-emerald-600" size={16} />
            <h4 className="text-sm font-semibold text-slate-900">Quyết định ({summary.decisions.length})</h4>
          </div>
          <ul className="space-y-2">
            {summary.decisions.map((d, i) => (
              <li key={i} className="flex items-start gap-2 text-sm text-slate-700">
                <span className="text-emerald-500 mt-0.5">•</span>
                <span>{d}</span>
              </li>
            ))}
          </ul>
        </div>
      )}

      {/* Risks & Open Questions */}
      {summary.risksAndQuestions && (
        (summary.risksAndQuestions.risks?.length > 0 || summary.risksAndQuestions.openQuestions?.length > 0)
      ) && (
        <div className="grid grid-cols-1 md:grid-cols-2 gap-3">
          {summary.risksAndQuestions.risks && summary.risksAndQuestions.risks.length > 0 && (
            <div className="p-4 bg-rose-50/50 rounded-xl border border-rose-200/80">
              <div className="flex items-center gap-2 mb-2">
                <AlertTriangle className="text-rose-600" size={16} />
                <h4 className="text-sm font-semibold text-rose-900">Rủi ro</h4>
              </div>
              <ul className="space-y-1 text-sm text-rose-800">
                {summary.risksAndQuestions.risks.map((r, i) => <li key={i}>• {r}</li>)}
              </ul>
            </div>
          )}
          {summary.risksAndQuestions.openQuestions && summary.risksAndQuestions.openQuestions.length > 0 && (
            <div className="p-4 bg-amber-50/50 rounded-xl border border-amber-200/80">
              <div className="flex items-center gap-2 mb-2">
                <HelpCircle className="text-amber-600" size={16} />
                <h4 className="text-sm font-semibold text-amber-900">Câu hỏi mở</h4>
              </div>
              <ul className="space-y-1 text-sm text-amber-800">
                {summary.risksAndQuestions.openQuestions.map((q, i) => <li key={i}>• {q}</li>)}
              </ul>
            </div>
          )}
        </div>
      )}

      {error && <p className="text-sm text-rose-600">{error}</p>}
    </div>
  );
};
```
