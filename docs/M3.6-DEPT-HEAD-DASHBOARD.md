## 0. BỐI CẢNH & VẤN ĐỀ

### 0.1. Vấn đề user báo cáo (screenshot evidence)

User là **DEPARTMENT_HEAD** mở Dashboard, gặp 3 vấn đề chính:

| # | Vấn đề | Evidence |
|---|--------|----------|
| **V1** | Nhấn vào đâu cũng không ra trang chi tiết | `DepartmentHeadDashboardLayout.tsx`: Project row chỉ có 1 link nhỏ ở góc phải (`<Link to="/projects/${proj.id}/tasks">`); Sprint card chỉ có 1 link tới Kanban; Member card chỉ có button "Giao việc"; Quick Task item **không clickable** |
| **V2** | Không có chức năng gán/đổi PM | Không tồn tại UI swap PM trong dashboard layout; chỉ có ở `CreateProjectModal` lúc tạo mới |
| **V3** | Bảng sprint nhìn vô nghĩa | Mỗi sprint chỉ có 1 progress bar + % done; **THIẾU** burndown chart, member contribution, risk alert, blocker list |

### 0.2. Mục tiêu

Làm cho mọi thẻ trong dashboard **clickable → mở modal chi tiết** với dữ liệu phong phú, đồng thời bổ sung **Sprint Management** thực sự hữu ích cho Trưởng phòng.

### 0.3. Nguyên tắc thiết kế (UX)

- **Modal first** (đã chốt với user): Click → modal ngay, không navigate
- **Progressive disclosure**: Overview card gọn → Click → Modal với detail đầy đủ
- **Zero new routes**: Tận dụng modal, không tạo thêm page riêng
- **Action-oriented**: Mỗi modal có ít nhất 1 action (đổi PM, assign task, xem chi tiết, v.v.)
- **Bauhaus aesthetic** giữ nguyên: rounded-2xl, gradient subtle, shadow-sm

## 1. NGHIỆP VỤ

### 1.1. Scope chốt với user

| # | Tính năng | Mức độ | Ghi chú |
|---|-----------|--------|---------|
| **F1** | Click Project card → **ProjectDetailModal** | 🔴 Bắt buộc | Modal với overview + tasks + members + PM info |
| **F2** | Click Sprint card → **SprintManagementModal** | 🔴 Bắt buộc | Burndown + member contribution + blocker list + risk alert |
| **F3** | Click Member card → **MemberProfileModal** | 🔴 Bắt buộc | Thông tin cá nhân + task open/overdue + 7-day attendance history |
| **F4** | Quick Task item clickable → **QuickTaskDetailModal** | 🟡 Nên có | Modal với full info + action buttons |
| **F5** | **Swap PM modal** (quick_swap_modal) | 🔴 Bắt buộc | Từ ProjectDetailModal → nút "Đổi PM" → modal chọn PM mới |
| **F6** | **Sprint Burndown chart** (A) | 🔴 Bắt buộc | Recharts line chart, actual vs ideal line |
| **F7** | **Member contribution table** (B) | 🔴 Bắt buộc | Avatar + tên + task done + SP done |
| **F8** | Modal rỗng states + Error handling | 🟡 Nên có | Skeleton loading, empty state, retry button |

### 1.2. Loại bỏ khỏi scope (defer)

- ❌ Real-time presence tracking trong member modal (đã có ở PM dashboard)
- ❌ In-modal editing project (chỉ xem + swap PM)
- ❌ Sprint editing/commenting (read-only cho Trưởng phòng)
- ❌ Notification trigger khi swap PM (defer tới M9.1)

### 2.1. Flow tổng thể

```
DEPT_HEAD Dashboard
│
├── Project Card (click anywhere)
│   └── ProjectDetailModal
│       ├── Tab 1: Overview (mô tả, dates, status, members count)
│       ├── Tab 2: Members (grid avatar + tên + role)

│   └── SprintManagementModal
│       ├── Header: Tên sprint + project + PM + days remaining
│       ├── [A] Burndown chart (Recharts line)

│       ├── Risk alert banner (nếu velocity thấp / scope creep)

│       ├── Recent project tasks (5 gần nhất)
│       └── [Nút: Giao việc] → QuickTaskModal (pre-selected assignee)
│
├── Quick Task item (click anywhere)
│   └── QuickTaskDetailModal
│       ├── Title + status + priority + due date
│       ├── Assignee + Assigned by
│       ├── Description (if any)
```

## 4. API DESIGN

### 4.1. New endpoints (5)

| # | Method | Endpoint | Auth | Mô tả |
|---|--------|----------|------|-------|
| 1 | `GET` | `/api/dashboard/dept-head/project/:id` | DEPT_HEAD, ADMIN | Full project detail cho modal |
| 2 | `GET` | `/api/dashboard/dept-head/sprint/:id` | DEPT_HEAD, ADMIN | Sprint detail + burndown + member contribution + blockers |
| 3 | `GET` | `/api/dashboard/dept-head/member/:id` | DEPT_HEAD, ADMIN | Member profile + 7-day attendance + recent tasks |
| 4 | `GET` | `/api/quick-tasks/:id` | Auth | Quick task detail (đã có sẵn — verify) |
| 5 | `PATCH` | `/api/projects/:id/swap-pm` | DEPT_HEAD, ADMIN | Swap PM — body: `{ newPmId, reason? }` |

### 4.2. DTO schemas (Zod)

```typescript
// dashboard-modals.dto.ts

// 1. GET /dashboard/dept-head/project/:id → ProjectDetailResponse
const ProjectDetailSchema = z.object({
  id: z.string(),
  name: z.string(),
  description: z.string().nullable(),
  color: z.string(),
  status: z.enum(['PLANNING', 'ACTIVE', 'ON_HOLD', 'COMPLETED', 'CANCELLED']),
  workflowType: z.enum(['SCRUM', 'KANBAN']),
  startDate: z.string().nullable(),
  endDate: z.string().nullable(),
  pm: z.object({
    id: z.string(), name: z.string(), email: z.string(), avatar: z.string().nullable(),
  }),
  createdBy: z.object({
    id: z.string(), name: z.string(), avatar: z.string().nullable(),
  }),
  memberCount: z.number(),
  taskCounts: z.object({
    total: z.number(), done: z.number(), inProgress: z.number(), blocked: z.number(), overdue: z.number(),
  }),
  progressPercent: z.number(),
  members: z.array(z.object({
    id: z.string(), name: z.string(), avatar: z.string().nullable(), projectRole: z.string(),
  })),
  recentTasks: z.array(z.object({
    id: z.string(), title: z.string(), status: z.string(), priority: z.string(), assigneeName: z.string().nullable(), updatedAt: z.string(),
  })).max(5),
  sprints: z.array(z.object({
    id: z.string(), name: z.string(), status: z.string(), progressPercent: z.number(), daysRemaining: z.number(), endDate: z.string(),
  })),
  activeSprint: z.object({
    id: z.string(), name: z.string(), progressPercent: z.number(), daysRemaining: z.number(), isAtRisk: z.boolean(),
  }).nullable(),
  riskLevel: z.enum(['LOW', 'MEDIUM', 'HIGH', 'CRITICAL']),
  riskReasons: z.array(z.string()),
});

// 2. GET /dashboard/dept-head/sprint/:id → SprintDetailResponse
const SprintDetailSchema = z.object({
  id: z.string(),
  name: z.string(),
  goal: z.string().nullable(),
  status: z.enum(['PLANNING', 'ACTIVE', 'COMPLETED']),
  startDate: z.string(),
  endDate: z.string(),
  daysRemaining: z.number(),
  daysTotal: z.number(),
  project: z.object({
    id: z.string(), name: z.string(), color: z.string(),
  }),
  pm: z.object({
    id: z.string(), name: z.string(), avatar: z.string().nullable(),
  }),
  totalTasks: z.number(),
  doneTasks: z.number(),
  inProgressTasks: z.number(),
  blockedTasks: z.number(),
  totalStoryPoints: z.number(),
  doneStoryPoints: z.number(),
  progressPercent: z.number(),
  burndown: z.array(z.object({
    date: z.string(),  // YYYY-MM-DD
    dayName: z.string(),  // T2, T3, ...
    ideal: z.number(),
    actual: z.number(),
    isToday: z.boolean(),
  })),
  memberContribution: z.array(z.object({
    userId: z.string(),
    userName: z.string(),
    avatar: z.string().nullable(),
    assignedTasks: z.number(),
    doneTasks: z.number(),
    doneStoryPoints: z.number(),
    contributionPercent: z.number(),
  })).max(10),
  blockedTasks: z.array(z.object({
    id: z.string(), title: z.string(), priority: z.string(),
    blockedDays: z.number(),
    assigneeName: z.string().nullable(),
  })),
  riskLevel: z.enum(['LOW', 'MEDIUM', 'HIGH', 'CRITICAL']),
  riskReasons: z.array(z.string()),
});

// 3. GET /dashboard/dept-head/member/:id → MemberProfileResponse
const MemberProfileSchema = z.object({
  id: z.string(),
  name: z.string(),
  email: z.string(),
  avatar: z.string().nullable(),
  position: z.string().nullable(),
  role: z.string(),
  department: z.object({ id: z.string(), name: z.string() }),
  stats: z.object({
    openTasks: z.number(),
    overdueTasks: z.number(),
    doneThisWeek: z.number(),
    doneThisMonth: z.number(),
  }),
  attendanceHistory: z.array(z.object({
    date: z.string(),  // YYYY-MM-DD
    dayName: z.string(),
    status: z.enum(['OFFICE', 'WFH', 'LEAVE', 'OFF', 'PENDING']),
    checkInTime: z.string().nullable(),
  })).length(7),
  recentQuickTasks: z.array(z.object({
    id: z.string(), title: z.string(), status: z.string(), dueDate: z.string(),
  })).max(5),
  recentProjectTasks: z.array(z.object({
    id: z.string(), title: z.string(), status: z.string(), projectName: z.string(), projectColor: z.string(),
  })).max(5),
});

// 4. PATCH /projects/:id/swap-pm → SwapPmRequest
const SwapPmSchema = z.object({
  newPmId: z.string().min(1, 'Vui lòng chọn PM mới'),
  reason: z.string().max(500).optional(),
});
```

```typescript
private buildSprintBurndown(sprint: any): BurndownPoint[] {
  const points: BurndownPoint[] = [];
  const start = new Date(sprint.startDate);
  const end = new Date(sprint.endDate);
  const today = new Date();
  const totalSP = sprint.tasks.reduce((acc: number, t: any) => acc + (t.storyPoints || 0), 0);
  const totalDays = Math.ceil((end.getTime() - start.getTime()) / 86400000);
  
  for (let i = 0; i <= totalDays; i++) {
    const date = new Date(start);
    date.setDate(start.getDate() + i);
    const ideal = Math.max(0, Math.round(totalSP * (1 - i / totalDays)));
    
    // Tính actual: tổng SP còn lại (chưa DONE) tính đến date này
    const actualRemaining = sprint.tasks
      .filter((t: any) => {
        if (t.status === 'DONE') {
          // Task done trước date này?
          return t.updatedAt > date;
        }
        return true; // Chưa done → vẫn còn
      })
      .reduce((acc: number, t: any) => acc + (t.storyPoints || 0), 0);
    
    points.push({
      date: date.toISOString().split('T')[0],
      dayName: date.toLocaleDateString('vi-VN', { weekday: 'short' }),
      ideal,
      actual: actualRemaining,
      isToday: date.toDateString() === today.toDateString(),
    });
  }
  
  return points;
}

private buildMemberContribution(tasks: any[]): MemberContribution[] {
  const map = new Map<string, MemberContribution>();
  for (const t of tasks) {
    if (!t.assignee) continue;
    const id = t.assignee.id;
    const existing = map.get(id) || {
      userId: id, userName: t.assignee.name, avatar: t.assignee.avatar,
      assignedTasks: 0, doneTasks: 0, doneStoryPoints: 0, contributionPercent: 0,
    };
    existing.assignedTasks++;
    if (t.status === 'DONE') {
      existing.doneTasks++;
      existing.doneStoryPoints += t.storyPoints || 0;
    }
    map.set(id, existing);
  }
  const totalDoneSP = Array.from(map.values()).reduce((acc, m) => acc + m.doneStoryPoints, 0);
  return Array.from(map.values())
    .map((m) => ({ ...m, contributionPercent: totalDoneSP > 0 ? Math.round((m.doneStoryPoints / totalDoneSP) * 100) : 0 }))
    .sort((a, b) => b.doneStoryPoints - a.doneStoryPoints)
    .slice(0, 10);
}

/**
```
```typescript
   * M3.6: Swap Project Manager
 * - Verify new PM is in the same department
 * - Update project.pmId
 * - Update projectMember.projectRole (old PM → MEMBER, new PM → PROJECT_MANAGER)
 * - Optional: Send notification to old/new PM (defer to M9.1)
 */
async swapPm(projectId: string, dto: SwapPmDto, actor: CurrentActor) {
  const project = await this.prisma.project.findUnique({
    where: { id: projectId },
    include: { pm: true, members: { include: { user: true } } },
  });
  if (!project) throw new NotFoundException('Dự án không tồn tại');

  // Verify actor can swap (DEPT_HEAD cùng phòng hoặc ADMIN)
  if (actor.role !== 'ADMIN') {
    if (actor.role !== 'DEPARTMENT_HEAD') {
      throw new ForbiddenException('Chỉ Trưởng phòng hoặc Admin mới có quyền đổi PM');
    }
    const newPm = await this.prisma.user.findUnique({
      where: { id: dto.newPmId },
      select: { departmentId: true },
    });
    if (!newPm || newPm.departmentId !== actor.departmentId) {
      throw new ForbiddenException('PM mới phải thuộc cùng phòng ban');
    }
  }

  // Verify new PM exists and is active
  const newPmUser = await this.prisma.user.findUnique({
    where: { id: dto.newPmId },
    include: { department: true },
  });
  if (!newPmUser || newPmUser.status !== 'ACTIVE') {
    throw new BadRequestException('PM mới không hợp lệ hoặc đã nghỉ việc');
  }
  if (newPmUser.id === project.pmId) {
    throw new BadRequestException('PM mới trùng với PM hiện tại');
  }

  const oldPmId = project.pmId;

  // Transaction
  return this.prisma.$transaction(async (tx) => {
    // 1. Update project.pmId
    const updated = await tx.project.update({
      where: { id: projectId },
      data: { pmId: dto.newPmId },
      include: {
        pm: { select: { id: true, name: true, email: true, avatar: true } },
      },
    });

    // 2. Update old PM's ProjectMember role → MEMBER
    if (oldPmId) {
      await tx.projectMember.upsert({
        where: { projectId_userId: { projectId, userId: oldPmId } },
        create: { projectId, userId: oldPmId, projectRole: 'MEMBER' },
        update: { projectRole: 'MEMBER' },
      });
    }

    // 3. Update new PM's ProjectMember role → PROJECT_MANAGER
    await tx.projectMember.upsert({
      where: { projectId_userId: { projectId, userId: dto.newPmId } },
      create: { projectId, userId: dto.newPmId, projectRole: 'PROJECT_MANAGER' },
      update: { projectRole: 'PROJECT_MANAGER' },
    });

    // 4. Log audit (defer - no audit table yet)
    
    return updated;
  });
}
```

```typescript
  orange: 'from-orange-500 to-amber-600',
  teal: 'from-teal-500 to-blue-600',
  indigo: 'from-indigo-500 to-purple-600',
  rose: 'from-rose-500 to-red-600',
  amber: 'from-amber-500 to-orange-600',
};

export function ModalShell({
  isOpen, onClose, title, subtitle, size = 'lg', children, footer, headerGradient = 'blue', preventBackdropClose = false,
}: ModalShellProps) {
  // ESC key handler
  useEffect(() => {
    if (!isOpen) return;
    const handleEsc = (e: KeyboardEvent) => { if (e.key === 'Escape') onClose(); };
    document.addEventListener('keydown', handleEsc);
    document.body.style.overflow = 'hidden'; // Lock scroll
    return () => {
      document.removeEventListener('keydown', handleEsc);
      document.body.style.overflow = '';
    };
  }, [isOpen, onClose]);

  if (!isOpen) return null;

  return (
    <div className="fixed inset-0 z-50 flex items-center justify-center p-4">
      {/* Backdrop */}
      <div
        className="absolute inset-0 bg-slate-900/50 backdrop-blur-sm"
        onClick={() => !preventBackdropClose && onClose()}
      />
      
      {/* Modal Content */}
      <div className={`relative w-full ${sizeClasses[size]} max-h-[90vh] bg-white rounded-3xl shadow-2xl overflow-hidden flex flex-col`}>
        {/* Header */}
        <div className={`bg-gradient-to-r ${gradientMap[headerGradient]} px-6 py-4 text-white`}>
```

```typescript
// File: backend/src/sprints/sprints.service.ts (extend)

/**
 * M3.6.1: Complete sprint với task decisions (Jira Standard)
 * 
 * Workflow:
 * 1. Validate sprint ACTIVE
 * 2. Nhận taskDecisions: { taskId, action: 'DONE' | 'CARRY_OVER' | 'CANCEL' }[]
 * 3. DONE tasks: giữ nguyên status = DONE
 * 4. CARRY_OVER tasks: 
 *    - Nếu carryOverToSprintId provided → move to that sprint
 *    - Nếu createNextSprint = true → tạo sprint mới + move to it
 *    - Nếu createNextSprint = false → move to backlog (sprintId = null)
 * 5. CANCEL tasks: 
 *    - Move to backlog (sprintId = null)
 *    - Có thể set status = CANCELLED (optional)
 * 6. Generate SprintReport snapshot
 * 7. Set sprint.status = COMPLETED
 * 
 * @param dto.taskDecisions: danh sách task chưa DONE phải có decision
 *                        (PM bắt buộc xếp từng task, không được bỏ sót)
 */
async completeWithChoices(id: string, dto: CompleteSprintDto, actor: CurrentActor) {
  const sprint = await this.prisma.sprint.findFirst({
    where: { id, deletedAt: null },
    include: { tasks: { where: { deletedAt: null } } },
  });
  if (!sprint) throw new NotFoundException('Sprint không tồn tại');
  
  const isPM = await this.projectAccessService.isProjectPM(sprint.projectId, actor.id);
  if (!isPM && actor.role !== Role.ADMIN) {
    throw new ForbiddenException('Chỉ PM hoặc Admin mới có quyền complete sprint');
  }
  
  if (sprint.status !== SprintStatus.ACTIVE) {
    throw new BadRequestException('Chỉ có thể complete sprint đang ACTIVE');
  }
  
  // Validate all non-DONE tasks có decision
  const nonDoneTasks = sprint.tasks.filter((t) => t.status !== TaskStatus.DONE);
  const decisionTaskIds = new Set(dto.taskDecisions.map((d) => d.taskId));
  const missingDecisions = nonDoneTasks.filter((t) => !decisionTaskIds.has(t.id));
  if (missingDecisions.length > 0) {
    throw new BadRequestException(
      `Phải xếp loại tất cả task chưa DONE. Thiếu quyết định cho ${missingDecisions.length} task(s): ${missingDecisions.map((t) => t.title).join(', ')}`
    );
  }
  
  // Validate decision values
  const validActions = ['DONE', 'CARRY_OVER', 'CANCEL'];
  for (const decision of dto.taskDecisions) {
    if (!validActions.includes(decision.action)) {
      throw new BadRequestException(`Action không hợp lệ: ${decision.action}`);
    }
  }
  
  return this.prisma.$transaction(async (tx) => {
    // 1. Snapshot metrics BEFORE any changes (for SprintReport)
    const tasksAtStart = sprint.tasks;
    const totalSPAtStart = tasksAtStart.reduce((sum, t) => sum + (t.storyPoints || 0), 0);
    const totalTasksAtStart = tasksAtStart.length;
    
    // 2. Process task decisions
    let carriedOverTaskIds: string[] = [];
    let cancelledTaskIds: string[] = [];
    let completedTaskIds: string[] = [];
    let carriedOverSP = 0;
    
    for (const decision of dto.taskDecisions) {
      const task = tasksAtStart.find((t) => t.id === decision.taskId);
      if (!task) continue;
      
      if (decision.action === 'DONE') {
        // Force mark as DONE (nếu PM xác nhận task đã xong dù chưa move)
        await tx.task.update({
          where: { id: decision.taskId },
          data: {
            status: TaskStatus.DONE,
            completedAt: new Date(),
            completedById: actor.id,
          },
        });
        completedTaskIds.push(decision.taskId);
      } else if (decision.action === 'CARRY_OVER') {
        carriedOverTaskIds.push(decision.taskId);
        carriedOverSP += task.storyPoints || 0;
      } else if (decision.action === 'CANCEL') {
        cancelledTaskIds.push(decision.taskId);
        await tx.task.update({
          where: { id: decision.taskId },
          data: {
            sprintId: null,  // Move to backlog
            status: task.status === 'DONE' ? task.status : task.status,  // giữ nguyên status
          },
        });
      }
    }
    
    // 3. Create next sprint nếu dto.createNextSprint = true
    let nextSprintId: string | null = null;
    if (dto.createNextSprint && carriedOverTaskIds.length > 0) {
      const newSprint = await tx.sprint.create({
        data: {
          projectId: sprint.projectId,
          name: dto.nextSprintName || `Sprint tiếp theo (${new Date().toLocaleDateString('vi-VN')})`,
          goal: dto.nextSprintGoal || null,
          parentSprintId: sprint.id,
          startDate: new Date(),
          endDate: new Date(Date.now() + (sprint.durationDays || 14) * 86400000),
          durationDays: sprint.durationDays || 14,
          status: SprintStatus.PLANNING,
          createdById: actor.id,
          capacityType: sprint.capacityType,
          capacityStoryPoints: sprint.capacityStoryPoints,
          capacityHours: sprint.capacityHours,
        },
      });
      nextSprintId = newSprint.id;
      
      // Move carry-over tasks to new sprint
      await tx.task.updateMany({
        where: { id: { in: carriedOverTaskIds } },
        data: { sprintId: newSprint.id },
      });
    } else if (carriedOverTaskIds.length > 0) {
      // Move to backlog (sprintId = null) or specified target sprint
      const targetSprintId = dto.carryOverToSprintId || null;
      await tx.task.updateMany({
        where: { id: { in: carriedOverTaskIds } },
        data: { sprintId: targetSprintId },
      });
    }
    
    // 4. Mark current sprint as COMPLETED + snapshot velocity
    const completedSP = sprint.tasks
      .filter((t) => completedTaskIds.includes(t.id) || t.status === TaskStatus.DONE)
      .reduce((sum, t) => sum + (t.storyPoints || 0), 0);
    
    const updatedSprint = await tx.sprint.update({
      where: { id },
      data: {
        status: SprintStatus.COMPLETED,
        completedAt: new Date(),
        velocity: completedSP,  // ⭐ Snapshot SP done
      },
    });
    
    // 5. Generate SprintReport snapshot
    const tasksAtEnd = await tx.task.findMany({
      where: { sprintId: id, deletedAt: null },
    });
    const totalSPAtEnd = tasksAtEnd.reduce((sum, t) => sum + (t.storyPoints || 0), 0);
    const notCompletedSP = tasksAtEnd.reduce((sum, t) => sum + (t.storyPoints || 0), 0);
    
    await tx.sprintReport.create({
      data: {
        sprintId: id,
        totalTasksAtStart,
        totalSPAtStart,
        totalTasksAtEnd: tasksAtEnd.length,
        totalSPAtEnd,
        completedTasks: completedTaskIds.length,
        completedSP,
        carriedOverTasks: carriedOverTaskIds.length,
        carriedOverSP,
        notCompletedTasks: tasksAtEnd.length - completedTaskIds.length,
        notCompletedSP,
        addedTasksMidSprint: 0,  // TODO: track separately
        addedSPMidSprint: 0,
        removedTasksMidSprint: 0,
        removedSPMidSprint: 0,
        scopeChangePercent: 0,
      },
    });
    
    return {
      sprint: updatedSprint,
      nextSprintId,
      carriedOverTaskIds,
      cancelledTaskIds,
      report: { totalSPAtStart, completedSP, carriedOverSP },
    };
  });
}
```

```typescript
 * 
 * @param dto.targetSprintId - null = move to backlog
 *                           - sprintId = move to specific sprint
 */
async moveTaskToSprint(taskId: string, dto: { targetSprintId: string | null }, actor: CurrentActor) {
  const task = await this.prisma.task.findUnique({
    where: { id: taskId },
    include: { project: true },
  });
  if (!task || task.deletedAt) {
    throw new NotFoundException('Task không tồn tại');
  }
  
  await this.projectAccessService.requireReadableProject(task.projectId, actor);
  
  // Check permission
  const isPM = await this.projectAccessService.isProjectPM(task.projectId, actor.id);
  const isAssignee = task.assigneeId === actor.id;
  const isCreator = task.createdById === actor.id;
  if (!isPM && !isAssignee && !isCreator && actor.role !== Role.ADMIN) {
    throw new ForbiddenException(
      'Chỉ PM, người được giao, người tạo hoặc Admin mới có thể chuyển sprint'
    );
  }
  
  // Validate target sprint
  if (dto.targetSprintId !== null) {
    const targetSprint = await this.prisma.sprint.findUnique({
      where: { id: dto.targetSprintId },
    });
    if (!targetSprint || targetSprint.projectId !== task.projectId || targetSprint.deletedAt) {
      throw new BadRequestException('Target sprint không hợp lệ hoặc không thuộc cùng project');
    }
    if (targetSprint.status === SprintStatus.COMPLETED) {
      throw new BadRequestException('Không thể move task vào sprint đã COMPLETED');
    }
  }
  
  return this.prisma.task.update({
    where: { id: taskId },
    data: { sprintId: dto.targetSprintId },
  });
}
```

```typescript
async getCapacityStatus(sprintId: string, actor: CurrentActor) {
  const sprint = await this.prisma.sprint.findFirst({
    where: { id: sprintId, deletedAt: null },
    include: { tasks: { where: { deletedAt: null } } },
  });
  if (!sprint) throw new NotFoundException('Sprint không tồn tại');
  
  await this.projectAccessService.requireReadableProject(sprint.projectId, actor);
  
  const totalSP = sprint.tasks.reduce((sum, t) => sum + (t.storyPoints || 0), 0);
  const totalHours = sprint.tasks.reduce((sum, t) => sum + (t.timeEstimate || 0), 0);
  
  let spStatus: 'OK' | 'WARNING' | 'OVERCOMMIT' = 'OK';
  let hoursStatus: 'OK' | 'WARNING' | 'OVERCOMMIT' = 'OK';
  let spPercent = 0;
  let hoursPercent = 0;
  
  if (sprint.capacityStoryPoints && sprint.capacityStoryPoints > 0) {
    spPercent = Math.round((totalSP / sprint.capacityStoryPoints) * 100);
    if (spPercent > 100) spStatus = 'OVERCOMMIT';
    else if (spPercent > 90) spStatus = 'WARNING';
  }
  
  if (sprint.capacityHours && sprint.capacityHours > 0) {
    hoursPercent = Math.round((totalHours / sprint.capacityHours) * 100);
    if (hoursPercent > 100) hoursStatus = 'OVERCOMMIT';
    else if (hoursPercent > 90) hoursStatus = 'WARNING';
  }
  
  return {
    sprintId,
    capacityType: sprint.capacityType,
    capacityStoryPoints: sprint.capacityStoryPoints,
    capacityHours: sprint.capacityHours,
    currentSP: totalSP,
    currentHours: totalHours,
    spPercent,
    hoursPercent,
    spStatus,
    hoursStatus,
    overallStatus: spStatus === 'OVERCOMMIT' || hoursStatus === 'OVERCOMMIT' 
      ? 'OVERCOMMIT' 
      : spStatus === 'WARNING' || hoursStatus === 'WARNING' 
      ? 'WARNING' 
      : 'OK',
  };
}
```

```typescript
export function CompleteSprintModal({ isOpen, onClose, sprintId, sprintName, onSuccess }: Props) {
  const [tasks, setTasks] = useState<Task[]>([]);
  const [loading, setLoading] = useState(true);

  const [createNextSprint, setCreateNextSprint] = useState(true);
  const [nextSprintName, setNextSprintName] = useState('');

    } finally {
      setLoading(false);
    }

  // Group tasks by action

    const carryOver: Task[] = [];
    const cancel: Task[] = [];

      if (action === 'DONE') done.push(task);
      else if (action === 'CARRY_OVER') carryOver.push(task);
      else if (action === 'CANCEL') cancel.push(task);
    }
    return { done, carryOver, cancel };
  }, [tasks]);
  
  const totalSP = useMemo(() => {
    return {
      done: decisions.done.reduce((sum, t) => sum + (t.storyPoints || 0), 0),

            onClick={handleSubmit}

            className="mt-4 inline-flex items-center gap-2 px-5 py-2.5 rounded-2xl bg-emerald-600 hover:bg-emerald-700 text-white font-black text-sm"

            <Sparkles className="w-4 h-4" />
            Complete Sprint

        <>

            Hủy

function Column({ title, description, tasks, totalSP, color, onDrop }: any) {
  const [isDragOver, setIsDragOver] = useState(false);
  const colorMap = {
    emerald: { bg: 'bg-emerald-50', border: 'border-emerald-300', text: 'text-emerald-900', badge: 'bg-emerald-600' },
    blue: { bg: 'bg-blue-50', border: 'border-blue-300', text: 'text-blue-900', badge: 'bg-blue-600' },
    slate: { bg: 'bg-slate-50', border: 'border-slate-300', text: 'text-slate-900', badge: 'bg-slate-600' },
  };
  const c = colorMap[color as keyof typeof colorMap];
  
  return (
    <div
      onDragOver={(e) => { e.preventDefault(); setIsDragOver(true); }}
      onDragLeave={() => setIsDragOver(false)}
      onDrop={(e) => {
        e.preventDefault();
        setIsDragOver(false);
        const taskId = e.dataTransfer.getData('taskId');
        if (taskId) onDrop(taskId);
      }}
      className={`rounded-2xl border-2 p-3 transition-all ${c.bg} ${c.border} ${isDragOver ? 'border-dashed ring-2' : ''}`}
    >
      <div className="flex items-center justify-between mb-2">
        <h3 className={`text-sm font-black uppercase tracking-wider ${c.text}`}>{title}</h3>
        <span className={`text-[10px] font-black px-2 py-0.5 rounded-full text-white ${c.badge}`}>
          {totalSP} SP
        </span>
      </div>
      <p className="text-[10px] text-slate-600 mb-3">{description}</p>
      <div className="space-y-2 min-h-[200px]">
        {tasks.map((task: Task) => (
          <DraggableTaskCard key={task.id} task={task} />
        ))}
      </div>
    </div>
  );
}
```

```typescript
import { useState, useEffect } from 'react';
```

```typescript
interface Props {
  currentSP: number;

  currentHours?: number;

export function CapacityBar({ currentSP, capacitySP, currentHours, capacityHours }: Props) {
  const spPercent = capacitySP > 0 ? Math.round((currentSP / capacitySP) * 100) : 0;
  const spStatus = spPercent > 100 ? 'OVERCOMMIT' : spPercent > 90 ? 'WARNING' : 'OK';
  
  const hoursPercent = capacityHours && capacityHours > 0 && currentHours
    ? Math.round((currentHours / capacityHours) * 100) : 0;
  const hoursStatus = hoursPercent > 100 ? 'OVERCOMMIT' : hoursPercent > 90 ? 'WARNING' : 'OK';
  
  const colorMap = {
    OK: { bg: 'bg-emerald-500', text: 'text-emerald-700', border: 'border-emerald-300' },
    WARNING: { bg: 'bg-amber-500', text: 'text-amber-700', border: 'border-amber-300' },
    OVERCOMMIT: { bg: 'bg-rose-500', text: 'text-rose-700', border: 'border-rose-300' },
  };
  
  return (
    <div className="space-y-3">
      {/* SP Capacity */}
      {capacitySP > 0 && (
        <div>
          <div className="flex items-center justify-between mb-1">
            <span className="text-[10px] font-black uppercase text-slate-500">Story Points</span>
            <span className={`text-xs font-black ${colorMap[spStatus].text}`}>
              {currentSP} / {capacitySP} SP ({spPercent}%)
            </span>
          </div>
          <div className={`w-full h-2 rounded-full ${spStatus === 'OK' ? 'bg-emerald-100' : spStatus === 'WARNING' ? 'bg-amber-100' : 'bg-rose-100'} overflow-hidden`}>
            <div
              className={`h-full ${colorMap[spStatus].bg} transition-all duration-500`}
              style={{ width: `${Math.min(spPercent, 100)}%` }}
            />
          </div>
          {spStatus === 'OVERCOMMIT' && (
            <div className="text-[10px] text-rose-600 font-bold mt-1">
              ⚠ Vượt capacity {spPercent - 100}%. Cân nhắc giảm scope.
            </div>
          )}
        </div>
      )}
      
      {/* Hours Capacity */}
      {capacityHours && capacityHours > 0 && currentHours !== undefined && (
        <div>
          <div className="flex items-center justify-between mb-1">
            <span className="text-[10px] font-black uppercase text-slate-500">Hours</span>
            <span className={`text-xs font-black ${colorMap[hoursStatus].text}`}>
              {currentHours} / {capacityHours}h ({hoursPercent}%)
            </span>
```
